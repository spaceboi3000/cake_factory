Why did my battery deplete so quickly?

When clock frequency increases from 1.0 GHz to{' '} 5.0 GHz (a 5× increase), cake throughput only increases 5×. However, dynamic power scales with the cube of the frequency: (5.0 / 1.0)³ = 125× greater power consumption!

// DVFS & VLIW EQUATIONS Throughput = Base × f × (VLIW ? 2 : 1) Power = Base × f³ × (VLIW ? 2 : 1) Max Yield occurs at min(f)

How does CPU Instruction Pipelining work?

Without pipelining, a single processor unit must execute every stage (Bake → Frost → Box, analogous to Fetch → Decode → Execute) before starting the next item, resulting in CPI = 3.0.

With pipelining enabled, 3 separate hardware units operate in parallel. While cake #3 is being boxed, cake #2 is being frosted, and cake #1 is being baked. After an initial 3-cycle fill latency, one finished cake rolls off the conveyor belt every single clock cycle (CPI = 1.0, achieving a 3× speedup).

// PIPELINING METRICS Latency = k cycles (k = 3 stages) Throughput = 1 item / cycle (Peak) Speedup = (k · n) / (k + n - 1) → 3×
