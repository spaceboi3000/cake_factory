Why did my battery deplete so quickly?

When clock frequency increases from 1.0 GHz to 5.0 GHz (a 5× increase), cake throughput only increases 5×. However, dynamic power scales with the cube of the frequency: (5.0 / 1.0)³ = 125× greater power consumption!

How does CPU Instruction Pipelining work?

Without pipelining, a single processor unit must execute every stage (Bake → Frost → Box, analogous to Fetch → Decode → Execute) before starting the next item, resulting in CPI = 3.0.

With pipelining enabled, 3 separate hardware units operate in parallel. While cake #3 is being boxed, cake #2 is being frosted, and cake #1 is being baked. After an initial 3-cycle fill latency, one finished cake rolls off the conveyor belt every single clock cycle (CPI = 1.0, achieving a 3× speedup).

// PIPELINING METRICS Latency = k cycles (k = 3 stages) Throughput = 1 item / cycle (Peak) Speedup = (k · n) / (k + n - 1) → 3×

How it works · Architecture & Cache Details

• Cache Mapping: 6 independent cake orders with 3 toppings (🍓 Strawberry, 🍫 Chocolate, 🌼 Vanilla). Each jar has enough for all requested cakes and remains on the fast shelf after baking. Jars represent reusable cached data: CPU reads data without destroying it.

• Associativity & Latency: 1 baker, 2 shelf slots (fully associative). A cache hit takes 1 baking cycle. A cache miss incurs 3 wait cycles for the pantry round-trip plus 1 baking cycle (4 cycles total). When the shelf is full, the least recently used (LRU) jar is evicted.

How it works · Cache Lines & Spatial Locality

• Pantry Pairs as Cache Lines: Pantry pairs stand for adjacent memory addresses fetched together in a cache line. Fetching either topping automatically brings its whole pair after 3 waiting cycles.

• Fast Shelf Capacity: Stores one pair (2 items total). Fetching the other pair evicts both items from the shelf.

• Temporal vs Spatial Hits: Accessing the exact same item again is a temporal hit. Accessing the neighboring item brought along in the same cache line is a spatial hit!
